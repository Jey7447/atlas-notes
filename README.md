# Atlas Notes

Atlas Notes 2.0 is a cloud-first, offline-capable, zero-AI workspace for handwriting, typed notes, infinite canvas work, PDF annotation, audio, media and collaboration.

## Product rule

Atlas does not use AI.

No AI chat, summaries, transcription, OCR, semantic search, generated notes or LLM integrations.

## Current direction

- Flutter client
- Supabase cloud backend
- Drift/SQLite local database
- Offline-first writes
- Background synchronization
- Realtime collaboration foundation
- Private cloud storage
- Android/tablet first

## Repository

The original main branch contains the browser prototype.

The atlas-2.0 branch is the new production architecture and will become the primary implementation once the foundation is validated.

## Development phases

1. Foundation and cloud schema
2. Local database and sync engine
3. Notebook/note/page system
4. Canvas and stylus engine
5. PDF studio
6. Media and audio
7. Organization/search/templates
8. Sharing and collaboration
9. Import/export
10. Platform polish and release hardening
